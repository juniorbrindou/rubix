# Marque

- **Nom** : Rubix Coach (choisi par l'utilisateur le 2026-11-22). Proche de la marque « Rubik's » : à revoir avant une
  publication sur un store.
- **Icône** (choisie le 2026-11-22, variante « A ») : un cube à moitié recopié sur fond jaune, le doigt qui
  colorie une case — on recopie les couleurs de son vrai cube, l'app aide à le résoudre. Sources :
  `icon-a-full.svg` (icône pleine), `icon-a-fg.svg` (avant-plan Android, ramené aux 2/3 centraux visibles),
  `icon-a-mono.svg` (icônes à thème). `final-a.py` les génère, `render-a.js` produit les PNG à copier dans
  `assets/` (Chromium du serveur). Fond de l'icône adaptative : `#FFD500` dans `app.json`.
- La première icône (fond noir, `icon-full.svg`, `final.py`, `render.js`) est remplacée : dessin trop petit, fond
  qui s'effaçait parmi les autres applis.
- Les planches `logos*.png` gardent les pistes écartées.
