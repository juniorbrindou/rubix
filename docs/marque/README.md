# Marque

- **Nom** : Rubix Coach (choisi par l'utilisateur le 2026-11-22). Proche de la marque « Rubik's » : à revoir avant une
  publication sur un store.
- **Icône** : le doigt qui colorie une case d'un cube encore en partie gris — on recopie les couleurs de son vrai
  cube, l'app aide à le résoudre. Sources : `icon-full.svg` (icône pleine), `icon-fg.svg` (avant-plan Android,
  dans la zone sûre), `icon-mono.svg` (icônes à thème). `final.py` les génère, `render.js` produit les PNG de
  `assets/` (Chromium du serveur). Fond de l'icône adaptative : `#111111` dans `app.json`.
- Les planches `logos*.png` gardent les pistes écartées.
